# CODE METHOD

A framework to interact with a second brain proposed by Tiago Forte in the book, Building a Second Brain. 

1. Capture: Keep what resonates, and leave the rest 
2. Organize: Save for actionability 
3. Distill: Find the essence 
4. Express: Take action 

### CAPTURE 

We will consume more than we can handle in the modern world, but there will be things that stick out to us for some reason. The **why** is not that important here, but it's important to *capture* the **what** if something does resonate with us. This is so that we can make thoughts tangible. 

### ORGANIZE 

The school system often teaches us to categorize information by topic. But often times information cannot be confined in a single topic, and forcing this structure makes it harder to resurface the ideas later. Thus, it's more effective to organize information based on how you will be using the information later on. 

### DISTILL 

Similar to the concept of atomic notes. Distill the information into its essence. Ask yourself, "What is this information trying to convey in a sentence or two?"

### EXPRESS

Knowledge is only as valuable as its application. So show your work! Take action!
